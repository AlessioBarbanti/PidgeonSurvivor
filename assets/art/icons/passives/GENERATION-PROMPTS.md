# Prompt ImageGen — icone passive rimanenti

Ogni blocco è un prompt completo e indipendente, pronto da inviare a ImageGen.
L'output atteso è un master PNG RGBA quadrato con sfondo trasparente, da elaborare
con `tools/process-passive-icon.ps1` prima dell'uso runtime. I nomi file proposti
seguono gli ID già presenti in `data/friends/`.
